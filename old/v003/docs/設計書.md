# MataTabi 設計書（v003）

N西市の観光客向けWebアプリ。ヘッダーのアプリ名は仮に「MataTabi」とする。認証は置かない。

ホームは、街並みの背景の上に2枚のカードを置く。候補の詳細と記録の詳細だけを、すりガラスのモーダルで開く。

スポット名は星凪諸島スタンプラリーのサンプルを、N西市の実証用コンテンツとして使っている。再訪そのものはサンプルでは未観測であり、このアプリは予測をしない。

## 1. システム構成

ブラウザだけで動く。サーバ処理、外部API、外部DB、クラウドストレージは使わない。

```text
ブラウザ
  index.html
    css/app.css
    img/town.svg          画面いっぱいの海辺の町と桜並木。同名で差し替える
    img/spots/{id}.svg    カード内のサムネイル。同名で差し替える
    js/catalog.js         スポットと季節の静的データ
    js/engine.js          候補の採否
    js/store.js           localStorage の読み書きと検証
    js/ui.js              画面描画とモーダル
```

| 区分 | 内容 |
| --- | --- |
| 実行場所 | このPCのブラウザ。スマートフォンとタブレットは開発者ツールの画面幅で確認する |
| 配信 | 静的ファイル。`v003` をローカルに開く |
| 保存 | `localStorage` キー `matatabi-v003`。ログイン情報は持たない |
| 外部通信 | なし。Content-Security-Policy で `self` 以外を拒否する |
| ライブラリ | なし。ライセンス対象の第三者コードは含まない |
| 背景 | オリジナルSVG。海辺の町、桜並木、青空。基準画像の人物や文言は写していない |

画面遷移は URL のハッシュで行う。

| ハッシュ | 画面 | 下部ナビの選択 |
| --- | --- | --- |
| `#/home` | ホーム | ホーム |
| `#/memories` | 思い出 | 思い出 |
| `#/discover` | 発見 | 発見 |
| `#/favorites` | お気に入り | お気に入り |
| `#/cards` | 3枚の編集 | 発見 |

## 2. 画面設計

背景はビューポート全体に `img/town.svg` を敷き、その上に藍の薄いグラデーションを重ねて文字の可読性を保つ。内容の列は幅520pxまで中央に置く。カードは白のすりガラス、角丸、控えめな影。対応ブラウザでは `backdrop-filter` を使い、非対応では白の不透明度を上げる。ボタンは白地に藍の文字で、角を丸くする。

下部ナビは4項目で固定する。各項目は24pxのアイコンと文字を持ち、押す領域の高さは56px以上にする。選択中は白い地に藍の枠を付ける。本文の下にはナビの高さ分の余白を置き、最後の操作がナビに隠れないようにする。

文字はカタログと固定文だけを `textContent` で出す。利用者の自由入力欄はない。

### S01 ホーム

- ヘッダー左にアプリ名「MataTabi」を出す。右に通知アイコンを置く。
- 保存した1枚の季節と、見ている季節が一致し、未確認のときだけ、通知アイコンに点を付ける。押すとアプリ内のお知らせを開く。プッシュ通知は送らない。
- カード1に、この端末の旅のサムネイルを最大4枚出す。ボタンは「思い出を振り返る」。サムネイルを押すと記録の詳細モーダルが開く。
- カード2に、候補のサムネイルを最大4枚出す。催しがある候補は、その催し名を写真の説明にする。ボタンは「未訪問地を探す」。サムネイルを押すと候補の詳細モーダルが開く。
- ホームのカード自体はモーダルにしない。

### S02 思い出

- 場所と季節の組を、この端末に追加または外す。
- 同じ組を二度は残さない。
- 行を押すと記録の詳細モーダルが開く。

### S03 発見

- 現地と帰宅後、見ている季節、移動負担の先出しをここで切り替える。
- 候補は1本のリスト。見出しも行も「未訪問」「訪問済み」とは書かない。ホームのボタン文言だけが「未訪問地を探す」である。
- 行を押すと候補の詳細モーダルが開く。
- 「3枚から1枚を残す」で編集画面へ進む。

### S04 お気に入り

- 保存した1枚を出す。未保存なら、その旨を書く。
- 見ている季節と一致すれば、条件が整った旨を書く。
- 保存を消せる。
- 「3枚を編集する」で編集画面へ進む。

### S05 3枚の編集

- 理由ごとに初期案を最大3枚出す。該当がなければそのカードは出さない。
- 各カードで理由と場所を、出せる候補だけから入れ替える。
- 「編集した1枚を保存する」で1枚だけ残し、お気に入りへ戻る。
- この画面は下部ナビの項目にしない。編集中は「発見」を選択中にする。

### 詳細モーダル

- 対象は候補の詳細と記録の詳細だけ。
- 背景の上に、すりガラスのカードとして開く。閉じる、背面を押す、Escape で閉じる。
- 開いているあいだ、背面の列は操作できない。

## 3. データ設計

カタログはコード内の固定データ。端末に残すのは次の形だけ。

```json
{
  "mode": "after",
  "season": "autumn",
  "showBurdenFirst": false,
  "history": [{ "spotId": "shio", "season": "autumn" }],
  "saved": { "spotId": "shio", "season": "winter", "reason": "season" },
  "noticeSeen": false
}
```

| 項目 | 値 | 意味 |
| --- | --- | --- |
| mode | `onsite` / `after` | 現地 / 帰宅後 |
| season | `spring` `summer` `autumn` `winter` | この端末で見ている季節 |
| showBurdenFirst | boolean | 移動負担を先に出す |
| history | spotId と season の配列 | 訪れた季節。最大40件 |
| saved | spotId, season, reason | 編集後に残した1枚。未保存は null |
| noticeSeen | boolean | 条件一致のアプリ内表示を確認したか |

初期の履歴は、星綾の潮見台の秋、虹灯りの夜市の秋、風詠みの灯台の夏。

スポットは7件。各スポットは春夏秋冬に1体験ずつ持つ。サムネイルのパスは `img/spots/{spotId}.svg`。背景は `img/town.svg`。どちらも同じパスのファイルを置き換えると画像だけ変わる。

読み込み時に、カタログに無い spotId、season、reason は捨てる。壊れたJSONは初期状態に戻す。

## 5. サジェスチョン規則

1. 履歴に同じスポットと同じ季節があれば、その体験は出さない。
2. まだその季節に行っていなければ、未訪問という言葉を付けずに候補へ入れる。
3. 現地モードは、見ている季節の体験だけを出す。今の季節にすでに行った場所は出ない。
4. 帰宅後モードは、別季節の訪問済みスポットと、まだ行っていない季節のスポットを同じ配列に混ぜる。
5. 並びは、現地なら今の季節、帰宅後なら次の季節を先にし、その中は所要が短い順。
6. 初期3枚は、季節が変わる続き、食が乗る続き、人がいる続きの先頭候補。無ければその枚は出さない。
7. 理由を変えたとき、同じ場所でその理由が出せれば場所を保つ。出せなければ、その理由の先頭に変える。
8. 低満足の代理として、移動負担を先に表示できる。候補の採否は変えない。
9. ホームのカード2は、この候補の先頭4件を写真にする。ボタンの文言だけ「未訪問地を探す」とする。

## 6. セキュリティ

- 認証は要件で不要。個人名、メール、トークンは持たない。
- CSP で自ファイル以外の読込を拒否する。
- 画面の文字列は `textContent` と `createTextNode` だけを使う。`innerHTML` は使わない。
- サムネイルのパスはカタログの spotId だけから組む。
- 保存値は表示前にカタログIDへ照合する。
- 自由記述を受け取らないため、入力起点のXSS面は選択肢の改ざんに限る。改ざんされたIDは候補生成で無視する。

## 8. 試験シナリオ

### TS01 ホームから進む

1. `v003/index.html` を開く。
2. ヘッダーが「MataTabi」で、カードに「思い出を振り返る」と「未訪問地を探す」があることを確認する。
3. 「未訪問地を探す」を押し、発見が選択中になることを確認する。
4. 発見の本文に「未訪問」「訪問済み」が無いことを確認する。

### TS02 詳細モーダル

1. ホームの思い出のサムネイルを押す。
2. 詳細カードが開き、背面のナビを操作できないことを確認する。
3. 「閉じる」で戻り、フォーカスがサムネイルに戻ることを確認する。

### TS03 1枚を残す

1. 発見から3枚の編集を開く。
2. 1枚の理由または場所を変える。
3. 保存し、お気に入りにその題だけが出ることを確認する。
4. 見ている季節をその季節に合わせ、通知の点と「約束の季節になりました」を確認する。

### TS04 記録

1. 思い出で、まだ残していない場所と季節を追加する。
2. 発見の候補から、その場所のその季節が外れることを確認する。
3. 外すと、再び候補へ戻ることを確認する。

## 9. 制約事項への対応

| 制約 | 対応 |
| --- | --- |
| クラウド、外部API、外部DB、外部ストレージ禁止 | 静的ファイルと localStorage のみ |
| PHP禁止 | HTML、CSS、JavaScript |
| スマホとタブレットのWeb | 幅に追従。確認はブラウザの画面幅 |
| 認証不要 | ログイン画面を置かない |
| XSS対応 | CSP、textContent、ID検証 |
| ライセンス | 自作コードと自作SVGのみ |
| コメント | 各ファイルの動作単位で記載 |
| 複雑にしない | カタログ、規則、保存、描画の4ファイル |
| 全面の風景とすりガラス | `town.svg`、グラデーション、半透明カード、白ボタン |
| 詳細だけモーダル | 候補詳細と記録詳細。ホームの2枚はページ内 |
| 非対応時の可読性 | `backdrop-filter` が無いときは白を濃くする |
